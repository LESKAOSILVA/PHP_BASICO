## Projetos

- 01-hello-world: primeira página em PHP
- 02-data-hora: data e hora do servidor
- 03-imc: calculadora de IMC
- 04-produtos: lista de produtos com array associativo

## Como executar

1. Instalar o Laragon e iniciar o Apache.
2. Colocar o projeto em C:\laragon\www\php-basico.
3. Acessar cada pasta pelo navegador usando localhost.
